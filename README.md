# lpla.github.io

Leopoldo Pla's personal website, published as plain static files by GitHub Pages.

There is no package manager, dependency lockfile, site generator, or build step.
The `.nojekyll` file tells GitHub Pages to serve the repository contents
directly.

## Editing

- Edit `index.html` for page content or structure.
- Edit files under `assets/` for styles, scripts, fonts, and images.
- Preview locally with `python3 -m http.server 8000`, then open
  <http://localhost:8000/>.

Publishing is a normal push to the `master` branch.
